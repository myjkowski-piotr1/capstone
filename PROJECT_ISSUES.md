# Planowane zgłoszenia GitHub Issues

Po opublikowaniu projektu utwórz każde z poniższych zadań jako osobne GitHub Issue. Na razie lista służy jako lokalna checklista, ponieważ projekt nie jest jeszcze połączony z repozytorium GitHub.

1. **[ZROBIONE] Wczytanie i sprawdzanie danych sprzedaży** — Wczytać CSV, oczyścić białe znaki, sprawdzić wymagane kolumny i wartości zamówień oraz jasno wskazywać nieprawidłowe wiersze.
2. **[ZROBIONE] Obliczanie dziennych statystyk** — Obliczać liczbę zamówień, przychód, średnią wartość zamówienia, najpopularniejszy produkt i region oraz liczbę zamówień spełniających próg.
3. **[ZROBIONE] Zapisywanie raportu CSV** — Zapisywać powtarzalny raport podsumowujący w folderze z raportami.
4. **[ZROBIONE] Dodanie testów automatycznych** — Testować czyszczenie danych, błędne dane, obliczenia, pusty plik wejściowy i zapis CSV.
5. **[W TRAKCIE] Zaplanowanie raportu w GitHub Actions** — Uruchamiać testy i generować raport codziennie, umożliwić ręczne uruchomienie oraz pobranie artefaktu.
