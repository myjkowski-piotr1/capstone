# Planowane zgłoszenia GitHub Issues

Zgłoszenia w repozytorium [capstone](https://github.com/myjkowski-piotr1/capstone). Issues 1–5 są zamknięte po implementacji i pomyślnym uruchomieniu workflow GitHub Actions.

1. **[ZAMKNIĘTE] [Wczytanie i sprawdzanie danych sprzedaży](https://github.com/myjkowski-piotr1/capstone/issues/1)** — Wczytać CSV, oczyścić białe znaki, sprawdzić wymagane kolumny i wartości zamówień oraz jasno wskazywać nieprawidłowe wiersze.
2. **[ZAMKNIĘTE] [Obliczanie dziennych statystyk](https://github.com/myjkowski-piotr1/capstone/issues/2)** — Obliczać liczbę zamówień, przychód, średnią wartość zamówienia, najpopularniejszy produkt i region oraz liczbę zamówień spełniających próg.
3. **[ZAMKNIĘTE] [Zapisywanie raportu CSV](https://github.com/myjkowski-piotr1/capstone/issues/3)** — Zapisywać powtarzalny raport podsumowujący w folderze z raportami.
4. **[ZAMKNIĘTE] [Dodanie testów automatycznych](https://github.com/myjkowski-piotr1/capstone/issues/4)** — Testować czyszczenie danych, błędne dane, obliczenia, pusty plik wejściowy i zapis CSV.
5. **[ZAMKNIĘTE] [Zaplanowanie raportu w GitHub Actions](https://github.com/myjkowski-piotr1/capstone/issues/5)** — Uruchamiać testy i generować raport codziennie, umożliwić ręczne uruchomienie oraz pobranie artefaktu. Workflow zakończył się powodzeniem i opublikował raport jako artefakt.
